# PdfCraft Web & PWA

PdfCraft in formato Progressive Web App (PWA), ottimizzato per browser desktop e dispositivi touch (iOS / iPadOS).

## Caratteristiche
- **100% Client-side WebAssembly**: Nessun invio di documenti al server; la visualizzazione, manipolazione, compilazione e firma dei PDF avvengono offline direttamente nel browser.
- **Supporto PWA per iOS e iPadOS**: Installa l'app sulla schermata Home da Safari per un'esperienza a schermo intero (standalone) senza barre del browser.
- **Offline Ready**: Funziona anche senza connessione internet grazie al Service Worker integrato.
- **Deploy Istantaneo su Vercel**: Pronto per il deploy immediato senza alcuna configurazione di build richiesta.
